# Contributing

Thanks for helping. Before you open a pull request:

- Read [`docs/PLAN.md`](docs/PLAN.md), especially the security model.
- `pnpm check` passes (Worker type check and tests, CLI formatting, lint and tests).
- New behaviour has a test; a fix starts with a failing one.
- No secrets, personal data or machine-specific paths in code, tests or fixtures.
